# Spam Email Detection

A beginner-friendly Machine Learning and NLP project that classifies emails as Spam or Ham.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Natural Language Processing (NLP)

## Machine Learning Techniques

- TF-IDF Vectorization
- Multinomial Naive Bayes

## Project Steps

1. Created a dataset containing Spam and Ham emails
2. Explored the dataset using Pandas
3. Split the data into training and testing sets
4. Converted email text into numerical features using TF-IDF
5. Trained a Multinomial Naive Bayes classification model
6. Evaluated the model using accuracy and classification report
7. Created a confusion matrix to analyze predictions
8. Tested the model on new unseen email messages

## Key Findings

- The model successfully classified test emails into Spam and Ham categories.
- TF-IDF was used to extract useful features from email text.
- Multinomial Naive Bayes was used for email classification.
- The model was tested on new email messages to verify its predictions.
